# Python Student Management System

A simple Student Management System built using Python for managing student records.

## Features

- Add new students
- View all student records
- Update student information
- Delete student records
- Simple menu-driven interface
- Input validation for student operations

## Technologies Used

- Python
- Lists
- Dictionaries
- Functions
- Loops
- Conditional Statements

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder.
4. Run the following command:

python student_management.py

## Menu Options

1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Exit

## Project Purpose

This project demonstrates basic Python programming concepts and CRUD-style operations for managing student records.
